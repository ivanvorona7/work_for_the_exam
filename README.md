Про проєкт
Цей макет інтернет-магазину техніки (на прикладі техніки Apple) був розроблений та зверстаний як екзаменаційний проєкт. Головним завданням було створення повнофункціонального, логічного інтерфейсу для електронної комерції, використовуючи виключно засоби семантичної верстки.
Ключові технічні та дизайнерські рішення:

1. Проєкт базується на чистому HTML5, де кожна секція (Header, Main, Aside, Footer) виконує свою логічну роль.
2. Реалізовано багаторівневе навігаційне меню та деталізований блок фільтрів товарів, що є критичним для UX інтернет-магазину.
3. Весь макет побудований на CSS3 без використання сторонніх CSS-фреймворків.
4. Для створення гнучкої сітки товарів, блоку фільтрів та адаптивних елементів інтерфейсу активно застосовувалися технології CSS Flexbox та Grid.
5. Для типографіки та кольорової схеми використано CSS-змінні, що забезпечує легкість підтримки та масштабування коду.
6. Реалізовано професійні картки товарів з чіткою ієрархією: зображення, назва, ціна, рейтинг та кнопка дії.
7. Створено інтуїтивно зрозумілі елементи інтерфейсу: перемикачі сторінок (пагінація), хлібні крихти (breadcrumbs), іконки кошика та обраного.
8. Верстка виконана з урахуванням принципів адаптивного дизайну (Responsive Web Design), що забезпечує коректне відображення макету на пристроях з різною роздільною здатністю екрана.
